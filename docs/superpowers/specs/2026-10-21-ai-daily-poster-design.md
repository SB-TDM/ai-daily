# 企微 AI 日报

一条命令。外部时钟在工作日启动它。它读 aihot.news 当天已经写好的日报，排成一页 HTML，截成一张图，发到企微群。同事在群里看到的，就是那一张图。

这不是网站，不是企微里的应用，也不是新闻采集器。企微只负责收图。命令跑在哪台机器上，不在这次设计里。

## 一次 Run

外部时钟可以在一个工作日里多次启动 Run。只有一张日报成功发到群里，这一天才结束。已经发过，就停止，这是唯一的正常停止。

命令本身不判断周末。工作日由外部时钟决定。这次设计不规定时钟放在哪里。

Run 只读一个地址：`https://aihot.news/api/v1/dailies/` 加上北京时间当天的日期，形如 `2026-10-21`。不读 agents-radar，不读 Hugging Face，不读 X，不截 aihot 的网页，也不使用昨天的日报。当天日报还没有，这次 Run 结束，但不把今天记成已发。

不调用模型。文案用 aihot 写好的标题、导语和摘要。

## 页面

HTML 只是印版，不发给群。浏览器把这一页整页截成一张图。截坏了不发。图超过 2MB 也不发。两种情况都不把今天记成已发。

版式是浅粉报纸。纸色偏粉，字是墨紫，栏目名是粉色贴纸。报头写「AI 日报」和日期，例如「2026年10月21日」。不写期号。纸上不放角色。字比普通正文略大。

头条用接口里的标题和导语。下面按接口里的栏目往下排。栏目名用他们的。每条印标题、摘要、来源名。来源名去掉括号尾巴，例如「Inception Labs：Blog（网页）」印成「Inception Labs：Blog」。不印网址。

`flashes` 不画。栏目名是「快讯」的也不画。

页脚不写「内部传阅」，也不印别的字。

## 投递

群里只发这一张图。图上的字不能点。发不出去，也不把今天记成已发。留到下次 Run 再试。

企微 webhook 地址只放在环境变量里，不进仓库。

## 不做

- 不自建采集平台。
- 不读 agents-radar 或 Hugging Face。
- 不截 aihot 的网页。
- 不调用模型来写稿或选稿。
- 不用模具。
- 不画快讯。
- 不放角色。
- 不做可点的链接消息。
- 不写期号。
- 不写「内部传阅」。
- 不在这次设计里决定时钟放在哪里。
