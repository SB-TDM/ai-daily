# 企微 AI 日报

一条命令。外部时钟在工作日启动它。它读别人已经整理好的 AI 新闻，画成一张海报，发到企微群。同事在群里看到的，就是那一张图。

这不是网站，不是企微里的应用，也不是新闻采集器。企微只负责收图。命令跑在哪台机器上，不在这次设计里。

## 一次 Run

外部时钟可以在一个工作日里多次启动 Run。只有一张日报成功发到群里，这一天才结束。已经发过，就停止，这是唯一的正常停止。

Run 只读两个 Upstream，并且只要北京时间当天的 Item：

- agents-radar 的每日 RSS
- Hugging Face Daily Papers

不读 X，不爬网页，不使用昨天的 Item。同一篇的英文孪生稿丢掉。一个 Upstream 失败，用另一个。两个都还没有当天内容，这次 Run 结束，但不把今天记成已发。

命令本身不判断周末。工作日由外部时钟决定。这次设计不规定时钟放在哪里。

## 素材板块

三步。先从素材库选一种视觉模具。再把标题、一句话、栏目名填进去。最后把填好的板块贴到日报上。

模具上不印死「论文」或「开源」。栏目名是填进去的字。一条 Item 只填进一个模具。

纸上每天都有报头和页脚。它们不是模具。报头只标日期，不写期号。页脚只写「内部传阅」，不印网址。纸上不放角色。

来源印成短标签，例如「HN · 10-21」，不印网址。正文是中文。产品名保持原文。

素材库有三种模具。模型按新闻的分量选一种。

- 大标题板：一条。栏目名、大标题、一句话。
- 短标题板：一条。栏目名、短标题。不写句子。
- 双栏板：并排两条。每边只有栏目名和短标题。

一条 Item 只进一个模具。双栏板的两边是两条不同的 Item。当天最多贴 5 个填好的模具，多出来的丢掉。

模型一个模具都没填时，用兜底，不空过这一天。兜底仍是选这三种模具、填字、再贴上。最重要的一条用大标题板。其余用短标题板。两条短的可以合成一块双栏板。

## 样子和投递

日报是一张偏二次元的海报，不是纯文本，也不是企微卡片。群里只发这一张图。图上的字不能点。

拼坏了不发半张。发不出去，也不把今天记成已发。两种情况都留到下次 Run 再试。

企微 webhook 地址只放在环境变量里，不进仓库。

## 不做

- 不自建采集平台，不部署 Horizon 或其他收集器。
- 不做可点的链接消息。
- 不写期号。
- 不在这次设计里决定时钟放在哪里。
