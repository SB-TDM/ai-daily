# Molds are filled, then pasted

A 素材板块 is a reusable visual mold, not a pre-printed category slot and not a sticky note. The library is three molds: 大标题板, 短标题板, and 双栏板. A Run chooses a mold by the weight of the item, fills in the title, the sentence, and the category name, then pastes the filled mold onto the 日报. 报头 and the footer stay on the paper. There is no character. We rejected a closed set of slots named 头版, 导读, 次条, 论文, 开源, and 产品, because those names are data, not molds.
